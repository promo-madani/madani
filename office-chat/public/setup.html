One-time setup for this computer

Checking this computer…

✅ This computer is set up. The chat connection is secure.

Open the chat

This takes about one minute. It makes the chat connection secure, which browsers require for voice messages, calls and screen sharing. You only do it once per computer.

  1. Download the chat certificate ⬇ Download certificate
  2. Install it (Windows)
    1. Open the downloaded file AI-Department-Chat-Certificate.crt.
    2. Click Install Certificate… then choose Current User and click Next.
    3. Choose Place all certificates in the following store, click Browse…, select Trusted Root Certification Authorities, then OK and Next.
    4. Click Finish, then Yes on the security question.
  3. Close all Chrome / Edge windows and open the chat again Open the chat
Android phone
  1. Tap Download certificate above.
  2. Open Settings → Security → Encryption & credentials → Install a certificate → CA certificate.
  3. Tap Install anyway and pick the downloaded file. Then open the chat again.
iPhone / iPad
  1. Open this page in Safari and tap Download certificate, then Allow.
  2. Open Settings → Profile Downloaded → Install.
  3. Open Settings → General → About → Certificate Trust Settings and switch it on.
Mac
  1. Open the downloaded file. It opens in Keychain Access.
  2. Double-click AI Department Chat CA, open Trust, and set When using this certificate to Always Trust.

Can't install it right now? Continue anyway. The browser will show a "Not private" warning: click Advanced → Proceed. Chat works, but the warning comes back each time.
